# Datasets

The baseline project uses self-play only.

## Tracked Data

- Training data generated by self-play should be stored under `data/`.
- Large binary files and generated datasets are ignored by git.
- Small metadata files that describe experiments may be tracked under `experiments/`.

## Future Options

- Human Gomoku game records for supervised warm starts.
- Fixed evaluation position sets.
- Synthetic rule-test fixtures.
